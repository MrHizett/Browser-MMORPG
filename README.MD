# Browser MMORPG - Java Backend + 3D Client

## Idea:

Multiplayer browser game with a Java backend server and a 3D web client,
will not be a complete game since developing a whole MMORPG is just slightly difficult, but it will have multiplayer with
a bunch of systems developed, mainly: combat, xp, accounts, gathering, inventories, crafting, player markets and dynamic dungeons (more on those later). 
Building this as a uni thesis project.
